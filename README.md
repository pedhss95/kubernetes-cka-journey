## 📈 Progress

**Day 01/07 — Understanding Pods**

Key learning:
A Pod has its own IP address, shared by all containers running inside it. Containers within the same Pod share the network namespace and can communicate through localhost.

Commands practiced:

```bash
kubectl get nodes
kubectl get pods -A
kubectl get pods -A -o wide
kubectl describe pod
```
